# Microsoft Edit integration audit before OGEdit 2.0.0

Reviewed **122 upstream commits** from fork point [`82cc84a610ded54d57f956285a8c4307c74bf364`](https://github.com/microsoft/edit/commit/82cc84a610ded54d57f956285a8c4307c74bf364) through [`cb6de0a8966aecd01d19a3541dab1829d0e679ca`](https://github.com/microsoft/edit/commit/cb6de0a8966aecd01d19a3541dab1829d0e679ca), freshly fetched on **2026-10-17**. Applicable changes were adapted into OGEdit rather than merged as Git ancestry. **This audit completed before the OGEdit 2.0.0 version bump**: version numbers, installation hashes and test measurements below identify the pre-release audit builds. See [the 2.0.0 release notes](releases/2.0.0.md) for the public release summary.

The working tree already contained substantial modernization and memory fixes. Its pre-integration files and manifest were saved at `target/upstream-audit/pre-integration.zip` and `target/upstream-audit/pre-integration-manifest.json`. Those features and fixes remain part of the integrated implementation.

## Changes delivered

- Editing: correct zero-width regex replacement, including empty replacements; atomic Replace All; exact-byte undo across joining graphemes; distinct saved/branched revisions; save boundaries; CRLF gap navigation; indentation endpoint handling; Backspace unindent; multiline paste protection in single-line inputs; checked large-file loading and complete buffered encoding output.
- Navigation and preferences: natural filename order; settings.json file associations; per-document language selection and Plain Text; explicit CLI `--goto` and negative lines; preserved quoted/mixed-separator GUI paths; missing save-parent creation through atomic saves.
- Terminal interaction: modal wheel isolation; horizontal/Shift/Alt wheel behavior; stable horizontal drag selection; menu click toggling; focus ancestry checks; complete UTF-8 mouse coordinates; Ctrl+Space; redirected stdin; valid startup/resize handling; hostile-text sanitization; complete Markdown text attributes.
- Portability: palette contrast and endian-independent colors; Unix interrupted I/O and terminal handling; metadata-based file identity; locale fallback; LoongArch SIMD fixes; safe x86 scalar fallback and synchronized SIMD dispatch.
- Localization and delivery: current translation catalogue with OGEdit additions retained; hyphenated locale handling with legacy underscore compatibility; workspace testing/linting; pinned Actions; Rust/Actions CodeQL; adapted source installer and current man page.

LSH compiler/runtime/grammar fixes were largely **already present** from the earlier modernization. A fetched-tree comparison found only three intentional differences: standalone package metadata in `Cargo.toml`, the pinned-nightly compatibility feature in `src/lib.rs`, and cache ownership accounting through `RuntimeState::heap_bytes()` in `src/runtime.rs`. The comparison is saved in `target/upstream-audit/lsh-differences.json`. The current 27 highlighting fixtures and additional syntax tests were incorporated now; missing Markdown style rendering was also implemented now. Existing grammars are not counted as newly written features.

Detailed rationale and regression locations: [core](upstream-core-integration.md), [platform/input/Unicode](upstream-platform-integration.md), [application/UI](upstream-ui-integration.md).

## Intentional differences

During this audit, the integrated build retained **version 1.2.4**; the subsequent public release is OGEdit 2.0.0. OGEdit keeps its own name, MSI/package delivery and GitHub release identity. Microsoft Azure/signing/WinGet configuration and Homebrew instructions are not copied. The Microsoft Inno installer includes recursive deletion of its application directory and another product's identity; the existing OGEdit installer remains in use.

The checked allocator, pinned nightly, standard arena-backed collections, existing error representation and original source layout remain. The temporary upstream `stdext` split is not recreated. Existing `serde_json`/`jsonc-parser` implementations replace the need for a second custom JSON/float parser; no equal-performance claim is made for that different architecture.

Newline conversion remains eager and reversible so editing views, editable search results and recovery observe the same current bytes. Paste remains a separate undo step. History stays bounded while retaining an entire transaction, including unusually large groups. The fork's gutter selection, multicursors, macros, safe saves, recovery, bounded syntax/fuzzy/search caches, configurable defaults and retro palette are preserved.

The new preferences file is separate from automatic `state.json`, preventing recent-file updates from overwriting a document being edited. GUI paths retain the previously requested convenience parsing, while CLI file locations now require `--goto` as upstream specifies.

Cross compilation on Windows does not constitute native Linux/macOS terminal execution. LoongArch SIMD and big-endian runtime behavior need their respective hardware or emulation for execution. Sanitizer and browser conclusions are limited to the runs explicitly recorded above. No upstream commit is silently classified as a completed runtime test merely because its code was reviewed or imported.
