More editing tools, safer persistence, and current Microsoft Edit fixes, with the retro terminal interface intact.

- Edit workspace search results directly, including matches in unsaved buffers, while respecting project ignore rules.
- Use multiple cursors, column selections, Alt-click insertion points, and reusable named macros with grouped undo.
- Edit CSV/TSV cells, JSON/JSONC values, and extracted log fields without losing surrounding source formatting.
- Switch files with fuzzy search and run commands from F2 or Ctrl+Shift+P.
- Get syntax highlighting, matching brackets, Markdown text styles, and a per-document language picker.
- Save atomically, recover unsaved work after a crash, and compare external changes before overwriting them.
- Open quoted Windows paths with mixed separators, preview the selected file's folder, or use the native Windows Browse dialog. File lists and completions use natural numeric ordering.
- Receive applicable fixes from 122 reviewed Microsoft Edit commits through `cb6de0a`: undo/redo and Unicode correctness, zero-width replacement, indentation, pasted input, terminal scrolling/resizing, Unix I/O, and updated translations.
- Reduce retained memory and handles through allocator, native-search, UI ownership, worker, watcher and recovery fixes. Search, data views and caches have explicit resource bounds.
- Detect external rewrites even when file size and timestamps stay unchanged, with bounded background content checks.
- Start on Linux installations that have versioned ICU runtime libraries without development symlinks. AppImage includes the required ICU and C++ libraries.

## Upgrading

- **CLI locations now require `--goto`:** use `ogedit --goto file.txt:12:3`. Ordinary arguments are literal filenames. Negative lines count from the end: `ogedit --goto file.txt:-1`. Open File retains location-suffix convenience.
- **Preferences are separate from saved state.** File → Preferences edits `~/.ogedit/settings.json`, including ordered `files.associations` rules. Existing shortcuts, recent files and project folders remain in `state.json`. `OGEDIT_DATA_DIR` still overrides the data directory.
- **Existing shortcuts remain:** Ctrl+D duplicates; Ctrl+Alt+D adds the next matching selection. F2 opens the command palette.
- **Linux downloads target glibc 2.39 or newer.** The DEB targets Ubuntu 24.04 and its ICU runtime package. RPM requires the distribution's `libicu`; portable archives also need ICU installed. AppImage bundles ICU and its C++ runtime. Use the source installer on older distributions.

## Validation

Local release preflight passed 316 Windows workspace tests, including an AddressSanitizer run, and 321 native Linux workspace tests in debug and optimized builds. Documentation tests and strict Clippy also passed. Browser-driven integration tests exercised the real Windows executable, including repeated document, data-panel, palette and Save As workloads; the audit records those binaries separately.

The release workflow additionally gates publication on native Windows, Linux and macOS tests, including the new runtime-loading and external-change regressions, plus all five build/package jobs. No coverage-guided fuzzing run is claimed.
