# Core integration of Microsoft Edit through cb6de0a

Compared the fork point `82cc84a610ded54d57f956285a8c4307c74bf364` with upstream `cb6de0a8966aecd01d19a3541dab1829d0e679ca`, fetched on 2026-10-17. This document covers the buffer, arena, helpers, fuzzy matcher, base64 and buffer benchmarks. Platform, UI, syntax and delivery changes are recorded by their respective integration reviews and the complete commit ledger.

The pre-integration working tree, including the modernization and memory fixes, was archived in `target/upstream-audit/pre-integration.zip`. The changes described here preserve multicursor operations, nested transactions, capacity preflight, native search ownership, bounded caches, recovery integration and exact-byte edits.

## Behavior integrated

- Word navigation crosses CRLF split by the gap, including both directions and repeated newlines.
- Multiline indentation excludes an ending selection at the next line's column zero.
- Backspace removes leading indentation to a tab stop; Ctrl+Backspace removes it to line start. Multiple cursors use the same rule as one undo transaction.
- Single-line inputs paste only the first line, handling LF, CRLF and terminal CR. A line-copy clipboard pastes at the field cursor.
- Zero-width regex replacement advances correctly, including empty replacements; Replace All is one undo group. Invalid patterns cannot leave a group open, no-op replacements preserve redo, and a changed search pattern cannot replace a stale match.
- File loading can reserve more than the former 4 GiB address range without committing all of it. Unknown/changed file sizes remain readable, and allocation exhaustion reports an error rather than a successfully truncated document.
- New edits receive fresh revision identities after undo and reload. Saving ends typing groups. A forced dirty state cannot collide with a history revision.
- History records exact byte offsets rather than relying on grapheme positions that can change after an edit. Only adjacent replacements coalesce; nonadjacent typing remains one user-visible undo group.
- Edits that join graphemes across the gap remeasure layout from a valid preceding anchor. This covers CRLF, combining marks, emoji joiners, regional indicators and malformed UTF-8 without rewriting source bytes.
- Newline preference changes without existing newlines are undoable too. Conversion writes are buffered, fully drained and flushed before a staged save returns.
- History uses `VecDeque` instead of individually allocated linked-list nodes. The trace benchmark only moves the cursor when necessary and models replacements as replacements.
- Arena allocations inline their small helpers, use 32 KiB commit increments on 32-bit targets and skip zero-byte copies during growth. Checked arithmetic, changed-alignment support, thread-local ownership and release-mode scratch checks remain intact.
- Explicit syntax language selection is cached alongside the filename for `files.associations`; changing either rebuilds the syntax cache.

## Validation and limits

The coordinating integration run records the final test results and browser evidence. The added tests cover upstream undo/redo roundtrips, joining edits at both edges, wrapping and resize, malformed UTF-8, automatic final newlines, deletion direction changes, replace-all, indentation, line movement, zero-width regular expressions, single-line paste, saved/loaded revision identity, encoding changes, metadata-only newline undo, multiple-cursor unindent, large virtual reservation and buffered UTF-16/UTF-32 conversion boundaries. The existing deterministic 131,200-operation transaction oracle remains part of the run.

Deliberate differences are source layout, the checked standard-allocator API, eager newline normalization, separate paste transactions, and bounded history that never cuts a transaction in half. No claim is made that the fork's source now exactly matches upstream, or that a >4 GiB file was physically loaded during this integration: the large-address test checks reservation and a small committed prefix without consuming gigabytes of memory.
